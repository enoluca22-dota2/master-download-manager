# Master Download Manager — development / build requirements.

# End users never install any of this: the packaged app bundles everything
# (see build.py). These are only for running from source and for building.

# The media engine (yt-dlp) is installed from the audited local source tree
# that sits next to this project, not from GitHub:
#
#     python -m pip install ../yt-dlp-master        (no [default] extra: it would add GPL mutagen)
#     python -m pip install -r requirements.txt
#
# `build.py setup` does both inside .venv.

Master Download Manager 4

One download manager for direct files (multi-connection, resumable),
media sites (videos, music, playlists) and BitTorrent (magnets and .torrent
files), with download queues, a scheduler and an optional browser extension.

Upgrading from an earlier version
  * This installs over your current copy. Your settings, download history,
    unfinished downloads and the browser extension pairing are kept
    (they live in %LOCALAPPDATA%\MasterDownloadManager).
  * Your history moves to a faster database on first start; the old
    download_history.json file is left in place as a backup.
  * Close Master Download Manager before continuing (Setup will ask).

What gets installed
  * The program, its own Python runtime, the yt-dlp media engine, FFmpeg,
    a JavaScript runtime (deno) and the libtorrent engine — nothing else
    needs to be installed.
  * Optionally the browser extension files (load them from the app's
    Settings -> Browser Integration).

Privacy
  The app only connects to the sites you download from. It never uploads
  your files, history or browser data. Update checks contact GitHub only
  when you ask (or weekly, if you switch that on).

Third-party components
  Master Download Manager is built on open-source software including
  yt-dlp (Unlicense), libtorrent (BSD-3-Clause), FFmpeg (LGPL-2.1+),
  deno (MIT), CustomTkinter (MIT), FastAPI (MIT) and Python (PSF). Some
  download-engine techniques were adapted from AB Download Manager
  (Apache-2.0). Full license texts are installed in the "licenses" folder.

Only download content you have the right to download. DRM-protected media
is not supported and is never circumvented.

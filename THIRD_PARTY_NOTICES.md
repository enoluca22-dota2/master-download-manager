# Third-Party Notices — Master Download Manager

Master Download Manager is built on third-party software. This file lists
every component that is **bundled in the distributed Windows build**, its
license, and what each license requires. The full license texts are shipped
in the `licenses/` folder next to the program (generated by
`tools/collect_licenses.py` from the exact versions that are bundled;
`licenses/inventory.json` is the machine-readable form).

Master Download Manager's own source code (the `ytd/` package, the GUI, the
browser extensions and build scripts) is not covered by any of the licenses
below. The project currently has no license file of its own; choosing one is
up to the author.

Versions below are those installed in the build environment on 2026-10-03.

## 6. Runtime network use

The application contacts the network **only** for the downloads the user
requests (websites, CDNs, BitTorrent peers/trackers/DHT) and, if the user
configures an update server and clicks "Check for updates", that server.
It never downloads yt-dlp, scripts, or binaries from GitHub/npm at runtime.

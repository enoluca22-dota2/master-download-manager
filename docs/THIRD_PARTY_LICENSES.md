# Third-party licenses — Master Download Manager 4.0.0

The authoritative, per-component list (versions, licenses, what each license
requires and how the build satisfies it) is
[`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md); the full license texts
of everything bundled are generated into [`licenses/`](../licenses) by
`tools/collect_licenses.py` from the exact versions in the build
(`licenses/inventory.json` is the machine-readable form). This page summarises
what changed for 4.0 and the obligations reviewed before redistribution.

## AB Download Manager (design reference)

| Item | Detail |
|---|---|
| Project | AB Download Manager 1.11.1 and its browser integration 1.5.0, by AmirHossein Abdolmotallebi |
| License | Apache License 2.0 (both repositories); no NOTICE file in either |
| What MDM used | Techniques and design ideas, re-implemented in Python/JavaScript: dynamic part splitting with a safe zone and an even initial split; chained global + per-download speed limiters; queue model with weekday start/stop schedule and stop-when-empty; power-action countdown; extension-based default categories; window layout; browser-download capture with type/size/site filters |
| What MDM did **not** use | No source files, code fragments, icons, images, translations, fonts or branding |

| Trademarks | "AB Download Manager" is used only to credit and compare. MDM uses its own name, icon and artwork (generated by `build_icons.py` / `tools/make_installer_art.py`) |

## New in 4.0

* No new runtime dependencies. History uses Python's built-in `sqlite3`;
  icons use Windows' own Segoe Fluent Icons font (not bundled).
* Dependency versions moved forward within the same licenses (e.g. FastAPI
  0.161.1, Pydantic 2.14.1, Pillow 13.0.0, certifi 2026.10.23); `licenses/`
  was regenerated from the bundled versions.
* Development/test-only tools (not distributed): pytest, httpx, PyInstaller,
  Playwright (Apache-2.0), pyflakes (MIT), Inno Setup (Inno Setup License).

## Deliberately excluded

* **mutagen** (GPL-2.0-or-later) — would make the bundle GPL; thumbnails are
  embedded with FFmpeg instead.
* **curl_cffi** (browser impersonation) — not bundled.

## Master Download Manager's own code

The repository does not yet declare a license for MDM's own source code;
choosing one is up to the author. Until then the default copyright rules
apply to it; the third-party licenses above apply only to their components.
